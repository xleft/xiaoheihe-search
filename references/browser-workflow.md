# 浏览器接入与网页操作

先检查当前会话实际提供的浏览器工具。优先复用用户授权的浏览器实例。工具能列标签页时，先核对实例和目标标签；只有空白页或未看到预期标签时，确认是否为独立实例。使用独立实例前须获用户授权，登录由用户完成。连接恢复后先列一次标签页，再打开小黑盒首页核对登录状态。

## 按宿主排障

### WorkBuddy 桌面版

- 扩展显示「未连接」时，先打开「设置 → 智能体 → 浏览器操控」。上方的「安装」是客户端运行时，Chrome 那行的「前往安装」是浏览器扩展。检查两者是否就位；缺安装或授权时，把具体入口交给用户。
- 扩展面板同时列国内版和国际版。用哪个客户端，就看对应那一行。修复后用 WorkBuddy 浏览器工具做一次最小连接验证，再继续原查询。
- 扩展快照主要给可交互元素，适合找搜索框、标签和帖子链接。确认工具支持目标区正文读取时，优先用该功能。评分数字、正文或回复漏读时，滚到对应区域，用截图核对。
- 全选复制会覆盖系统剪贴板，仅在用户同意、Chrome 窗口处于系统前台且焦点在网页正文时作为备选。先在本机比对复制前后的剪贴板文本，旧内容仅用于比对。工具返回「已执行」后，若内容未变化、读不到或与目标页面不符，直接切到目标区域截图。

[WorkBuddy 浏览器文档](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Right-Sidebar#独立浏览器使用)

### 豆包办公

- 已实测的环境使用独立浏览器，无法接管本机 Chrome。标签页列表与预期不一致时，先确认实例。人工接管明确提示不支持时，结束这条路径。用户同意后，使用宿主可用的扫码登录流程，由用户扫码并在小黑盒 App 确认。二维码出现失效提示时，由用户使用刷新后的新码。
- 站内组合词在实测中可能返回零条。先用完整游戏名搜索，再从游戏专属社区或内容结果筛选。列表滚动失败或重读后没有新增帖子时，直接阅读已取得的原帖样本。评分标签打不开时，报告当前可见值和未取得的历史数据。

### Codex、Hermes 与其他宿主

- **Codex 桌面版**使用当前会话可用的 Chrome 连接，在任务专用标签中操作。兼容脚本的用法见[主技能](../SKILL.md)。
- **Hermes Agent**需单独配置授权浏览器，选择 DeepSeek 模型不会提供浏览器连接。支持的本地 CLI 可用 `/browser status` 检查；`/browser connect` 属于本地 CLI。按会话实际可用的工具读取网页。Hermes 路线尚未端到端实测。[Hermes 浏览器文档](https://hermes-agent.nousresearch.com/docs/user-guide/features/browser#your-own-browser-via-cdp-browser-connect)
- **其他宿主**按实际能力选择导航、正文读取或截图。如果没有可用的浏览器工具，报告连接卡点。Codex 专用脚本仅适用于兼容的 CUA REPL。

打开小黑盒首页后，用头像和「发布内容」等可见控件核对登录状态；游戏页如果显示登录后才出现的字段，可作为补充证据。登录、验证和授权由用户在确认过的实例中处理。状态仍无法确认时，说明卡点并停止查询。

## 定向读页

| 任务 | 读什么 |
| --- | --- |
| 找游戏 | 在[站内搜索](https://www.xiaoheihe.cn/app/search)输入完整游戏名，从「综合」核对作品、版本和平台。游戏页典型路径为 `/app/topic/game/pc/…` 或 `/app/topic/game/mobile/…`。 |
| 找候选帖 | 使用游戏页内部的「社区」，或站内搜索的「内容」结果。只保留实际看到的原帖链接（`/app/bbs/link/…`）及筛选所需字段。热榜、时间或互动数按页面原样记录。 |
| 读原帖与回复 | 优先定向读取正文和当前可见的回复。需要补充代表性观点时，有限展开或滚动。复用同一轮中已经读到的结果；只有缺证据时才回到页面。推荐内容、列表摘要和显示的回复总数不计入实读样本。 |
| 查评分和资料 | 只读「游戏评价」、资料或价格等目标区域。按页面标签记录数值，区分评价人数、玩家数、在线人数和销量。 |

页面提示前往 App，或正文、回复仍无法读取时，记录具体限制。用户提供链接时只在核对为小黑盒原帖或对应游戏详情页后使用。
